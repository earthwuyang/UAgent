**Problem**: `check_if_alive()` only validates HTTP 200 status via `raise_for_status()`. It **does not check** if the response body is `{"status": "ok"}` vs `{"status": "not initialized"}`.

**Rationale**: Forces `wait_until_alive()` to **retry** until `client.initialized == True`, giving plugins/MCP time to finish.

### **Fix #2: Return HTTP 503 for Uninitialized State** (Better Semantics)

**File**: `OpenHands/openhands/runtime/action_execution_server.py`

**Patch**:
```python
@app.get('/alive')
async def alive():
    if client is None or not client.initialized:
        # Return 503 Service Unavailable instead of 200
        raise HTTPException(
            status_code=503,
            detail={'status': 'not initialized'}
        )
    return {'status': 'ok'}
```

**Rationale**: HTTP 503 signals "temporary unavailability," making `raise_for_status()` fail and triggering tenacity retries in `wait_until_alive()`.

### **Fix #3: Guard MCP Proxy Initialization** (Prevent Crash)

**File**: `OpenHands/openhands/runtime/action_execution_server.py`
